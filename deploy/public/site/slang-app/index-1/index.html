Welcome back to Slang.

Your programs are the blocks in the list on the left. Start with an example, then create your own.

  1. Open Double a number.
  2. Click the play button.
  3. Enter 21 in Input and click Send. Look for 42 in Output.
  4. Stop the program before editing. Switch between the visual graph and YAML using the editor toolbar.

Changes are saved in your private workspace. Use Export workspace in the bottom bar to keep a backup. Import its ZIP file using the upload control on the left.

Workspaces expire after 30 days of inactivity. This public playground supports computation and data processing; integrations with files and external services are available when you run Slang locally.
